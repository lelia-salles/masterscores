Editable musical score block for WordPress.

== Description ==

Master Scores is a WordPress block for composing and viewing simple musical scores directly in the editor.

It renders a musical staff using VexFlow and supports note playback with Tone.js.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/master-scores` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Add the "Master Scores" block in the editor.
